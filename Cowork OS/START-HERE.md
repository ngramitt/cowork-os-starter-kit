# Start Here: Cowork OS

A folder that turns your AI assistant into a real collaborator. It remembers what matters, keeps each part of your life or work in its own place, and gets more useful the more you use it. It works with **Claude** or **ChatGPT**.

Built by Noah Gramitt. Starter Kit v1.1.

## Set it up (about 10 minutes)

**1. Get the folder and put it somewhere permanent.**

- **From GitHub:** click the green **Code** button, choose **Download ZIP**, and unzip it. Inside is a folder called `Cowork OS`.
- **From a zip someone sent you:** unzip it to get the `Cowork OS` folder.

Move the `Cowork OS` folder somewhere permanent, like your Documents folder, and keep the name. This folder *is* your workspace from now on.

**2. Open it in your AI tool.**

| If you use... | Do this |
|---|---|
| **Claude desktop app** | Start a new task and add the `Cowork OS` folder to it. |
| **Claude Code** | Open a terminal in the folder and run `claude`. |
| **ChatGPT desktop app** | Use **Codex** (or **Work**, if your plan has it), open the `Cowork OS` folder, and make sure it's set to work **locally on your computer**, not in the cloud. |
| **Codex CLI** | Open a terminal in the folder and run `codex`. |

**3. Say hi.** Setup starts on its own: three quick rounds of questions about you, how you like to work, and two or three areas to start with. On ChatGPT, if setup doesn't start, say: **"Read AGENTS.md and follow it."**

That's it. From then on, open this same folder whenever you want your AI to work with you. Every conversation starts where the last one left off.

## Good to know

- **Your files stay on your computer.** Your AI tool reads the files it needs to help you. Don't store passwords or full account numbers here.
- **Python 3 is optional.** It powers the automatic health checks. Claude's desktop app has it built in; on a Mac using ChatGPT, you may be asked to install it. Everything works without it.
- **Nothing gets deleted** without your OK. The system shows you moves before it makes them.
- **The full guide** is `00_System/GUIDE.md`: how it works, what to say to it, and an FAQ.
